# Projeto Login

## Descrição
Este projeto é um site de login criado com HTML e CSS, desenvolvido com o objetivo de treinar a criação e estilização de formulários. Nele pratiquei campos de entrada, botões, validação visual e o uso de CSS externo para tornar o formulário responsivo e agradável visualmente.

## Tecnologias utilizadas
- HTML5
- CSS3
